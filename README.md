Игра - Камень / Ножницы / Бумага

Описание:
Всем знакомая игра в камень, ножницы бумагу
Выбирай, наслаждайся победой или попробуй ещё разок!

Инструкция:
1. Запустите `game.py`
2. Введите свой выбор: `Камень`, `Ножницы` или `Бумага`
3. Обрадоваться или попытать удачу сначала!

Функциональность:
- Выбор одного из трёх вариантов
- Запоминает и ведёт счёт побед / поражений
- Устойчив от ошибок
